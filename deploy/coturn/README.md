# Self-hosted TURN

This coturn instance relays WebRTC media from `turn.chat.nazmulhasan.dev` through `172.252.13.8`. It uses time-limited TURN REST credentials generated by the Relay API.

## DNS

Create a DNS-only `A` record:

```text
turn.chat.nazmulhasan.dev -> 172.252.13.8
```

Do not enable an HTTP proxy for this record; TURN needs direct UDP/TCP access.

## VPS deployment

Copy this directory to the VPS, create `.env` from `.env.example`, and put a long random secret in it. Use the exact same secret as `TURN_SHARED_SECRET` in the application's API `.env`.

Open the required ports on the VPS and provider firewall:

```bash
sudo ufw allow 3478/tcp
sudo ufw allow 3478/udp
sudo ufw allow 49160:49200/udp
```

Start and inspect coturn:

```bash
docker compose up -d
docker compose logs -f coturn
```

The API and coturn secrets must match. Restart the Relay API after changing its `.env`.
